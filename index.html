Controls & shortcut help

How the arrow keys choose subtitles

Left Arrow brings the nearest clip starting to the right of the playhead. Right Arrow brings the nearest clip ending to the left of the playhead.

Its beginning is extended back to the playhead while its end stays in place. Only the subtitle covering the playhead is trimmed to end there. Right Arrow extends the previous subtitle's end to the playhead and trims the covering subtitle's start if necessary. Undo restores both edits.

While active in Premiere: ← brings the next subtitle; → brings the previous subtitle; [ trims left; ] trims right. L and R keep their normal Premiere functions. Ctrl+Z / Ctrl+Shift+Z undo / redo subtitle edits only. Deactivate to release all subtitle shortcuts.

Use this panel's Undo for tool edits. Premiere's Edit → Undo uses a separate history and may undo an older edit. History lasts until the panel or project is reloaded. Existing overlaps must be recovered from a known-good project backup.
